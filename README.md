# محول الروابط (بديل مجاني لـ Bitly)

تطبيق ويب كامل لتقصير الروابط يعمل بـ **PHP + SQLite** مع واجهة حديثة بـ HTML/CSS/JS. يتيح إنشاء روابط قصيرة مخصصة، إدارة الروابط، وتسجيل النقرات مع التحكم في التفعيل والانتهاء—all مجاناً ودون أي تبعيات خارجية.

## المزايا
- تسجيل ودخول آمن بكلمات مرور مشفرة.
- إنشاء روابط قصيرة مع إمكانية تخصيص الـ slug وتحديد تاريخ انتهاء.
- تفعيل/تعطيل وحذف وتعديل الروابط في أي وقت مع عناوين داخلية.
- إحصائيات فورية: إجمالي النقرات ونشاط اليوم لكل رابط.
- تخزين محلي بـ SQLite، ويعمل على أي استضافة تدعم PHP.
- إعلانات قابلة للتبديل من ملف بيانات مستقل، وسكربت خارجي مخصص للتكاملات.

## المتطلبات
- PHP 8.1 أو أحدث مع امتداد PDO SQLite مفعّل.

## التشغيل محلياً
1. ثبّت الاعتمادية الوحيدة (لا توجد حزم خارجية). تأكد فقط من توفر PHP.
2. شغّل خادماً مدمجاً موجهاً إلى `index.php` حتى تمر جميع الروابط القصيرة عبر التطبيق:
   ```bash
   php -S localhost:8000 index.php
   ```
3. افتح المتصفح على http://localhost:8000.

عند التشغيل لأول مرة يُنشئ التطبيق قاعدة بيانات `data/shortlinks.db` تلقائياً. يمكن تغيير سر تجزئة الـ IP عبر متغير البيئة `IP_SALT`.

## بنية الملفات
- `index.php`: واجهة الموقع والمنطق الخلفي للتسجيل/الدخول، إنشاء الروابط، التحليلات، وإعادة التوجيه.
- `assets/style.css`: التنسيق العام واللوحة الحديثة.
- `assets/app.js`: وظائف الواجهة (نسخ الرابط، التمرير السلس، البحث، وإظهار محرر الرابط).
- `assets/external.js`: مكان مخصص للسكريبتات الخارجية أو أكواد الإعلانات/التحليلات.
- `data/`: مجلد قاعدة البيانات (يُنشأ تلقائياً، مع تجاهل ملفات `.db`).
- `data/ads.json`: ملف إعلانات متنوعة يمكن تعديله أو استبداله.
- `web.config`: قواعد إعادة كتابة للبيئات المعتمدة على IIS لتوجيه الروابط القصيرة إلى `index.php`.

## الأمان
- كلمات المرور مخزّنة بواسطة `password_hash`.
- تتبع النقرات يحفظ تجزئة IP فقط مع مرجع المتصفح والمصدر للحفاظ على الخصوصية.
- حماية CSRF عبر رمز جلسة لكل النماذج.

## ملاحظات
- الروابط غير النشطة أو المنتهية تعرض صفحة 404 مخصّصة.
- يمكن تعديل مظهر الموقع بسهولة عبر ملف CSS الواحد.
